# Bob Video Editor Kit

A self-contained distribution of the **🎬 Video Editor** workflow for Bob — bundles two skills, a custom mode, and a unified installer into a single zip archive anyone can unpack and run.

---

## Skills Overview

### `demo-video-editor`

Turns raw screen recordings and software demos into polished video assets.

| Capability | Detail |
|---|---|
| Source analysis | FFprobe metadata, Whisper transcript, contact-sheet thumbnails |
| Edit plan | JSON plan with trim, speed-ramp, audio-norm, clip-extract operations |
| Render | FFmpeg pipeline (loudness normalization to −16 LUFS, H.264/AAC output) |
| Transcription | whisper.cpp (local, no cloud) with configurable model size |
| Doctor check | `demo.py doctor` validates all dependencies in one step |

**Dependencies:** `ffmpeg-full` + `whisper.cpp` via Homebrew, Python 3.10+

### `add-voiceover`

Synthesizes voiceover audio from a timestamped cue file and mixes it into a video.

| Capability | Detail |
|---|---|
| TTS engine | mlx-audio / Kokoro 82M (Apple Silicon MPS — local, offline after first model download) |
| Voice | `af_heart` (warm American English female) |
| Cue format | `HH:MM:SS.ms | spoken text` — one line per cue |
| Output | Full video with mixed narration track, loudness-normalized |
| Check mode | `--check` flag validates cues against video duration before rendering |

**Dependencies:** `mlx-audio` + `misaki` + Kokoro model weights via `uv tool install`, `ffmpeg`

## Packaging the Kit

Run from the workspace root:

```bash
./scripts/package-video-editor-kit.sh
```

This produces:
- `dist/bob-video-editor-kit-<timestamp>.zip` — versioned archive
- `dist/bob-video-editor-kit.zip` — rolling symlink to the latest

### Packager options

| Flag | Description |
|---|---|
| `--output-dir <dir>` | Output directory (default: `./dist`) |
| `--output-name <name>` | Override zip filename |
| `--dry-run` | Preview what would be staged without writing |

### What is excluded from the archive

| Excluded | Reason |
|---|---|
| `__pycache__/`, `*.pyc` | Generated bytecode |
| `local/` | Working directories, installed-licenses cache |
| `tests/recordings/` | Potentially large/sensitive source recordings |
| `.DS_Store` | macOS metadata |
| `*.partial` | Incomplete render artifacts |

## Distributing and Installing

### For the distributor

```bash
# Package
./scripts/package-video-editor-kit.sh

# Share
ls -lh dist/bob-video-editor-kit.zip
```

### For the recipient

```bash
# Unpack
unzip bob-video-editor-kit.zip
cd bob-video-editor-kit

# Install skills + mode + settings into current workspace
bash install.sh

# Or install + pull all dependencies in one step (~850 MB on first run)
bash install.sh --install-deps
```

See `INSTALL.md` inside the kit for full options and manual install steps.

## Installer Behaviour (`install.sh`)

The installer is **idempotent** — it is safe to run multiple times:

| Step | Idempotency |
|---|---|
| Copy skills | Overwrites existing skill directories |
| Register mode | Skips if `slug: video-editor` already present in `custom_modes.yaml` |
| Merge `allowedCommands` | Uses Python `json.load` / `json.dump` — adds only missing entries, never removes user entries |
| Create `.bob/` | Only if it does not already exist |

### Installer flags

| Flag | Description |
|---|---|
| `--workspace <path>` | Target workspace (default: current directory) |
| `--dry-run` | Preview all changes without writing |
| `--install-deps` | Run both skill `setup.sh --install` scripts |
| `--skip-prereqs` | Bypass platform and dependency checks |

## Updating the Kit

When either skill is updated, re-run the packager:

```bash
./scripts/package-video-editor-kit.sh
```

The timestamped zip ensures prior versions are preserved in `dist/`. The rolling symlink always points to the newest build.
